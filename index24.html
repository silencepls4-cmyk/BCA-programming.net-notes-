इकाई III: डेटाबेस कनेक्टिविटी और ADO.NET

बीसीए पंचम (V) सेमेस्टर • विषय: सीएएससी-14T (.NET Programming) • शत-प्रतिशत परीक्षा-उपयोगी विस्तृत नोट्स

1. परिचय एवं परिभाषा (Introduction & Definition)

डॉट-नेट फ्रेमवर्क के अंतर्गत डेटाबेस से संवाद स्थापित करने और सूचनाओं का आदान-प्रदान करने के लिए ADO.NET (ActiveX Data Objects .NET) का उपयोग किया जाता है। यह डेटा-एक्सेस घटकों का एक ऐसा समूह है जो डेवलपर्स को रिलेशनल डेटाबेस (जैसे SQL Server, MySQL) के साथ आसानी से जुड़ने, डेटा पढ़ने, लिखने और अपडेट करने की अनुमति देता है।

ADO.NET मुख्य रूप से दो मॉडलों पर काम करता है: **Connected Architecture** (डेटा रीडर के माध्यम से सीधा कनेक्शन) और **Disconnected Architecture** (डेटासेट और डेटा एडाप्टर के माध्यम से ऑफलाइन डेटा प्रबंधन)।

2. मुख्य बिंदु एवं घटक (Key Points & Components)

  • Connection: डेटाबेस के साथ भौतिक संबंध स्थापित करता है (जैसे SqlConnection)।
  • Command: डेटाबेस पर SQL क्वेरी या स्टोर्ड प्रक्रिया निष्पादित करता है (जैसे SqlCommand)।
  • DataReader: डेटाबेस से केवल-पठनीय (Read-only) और तेज गति से डेटा पढ़ने का साधन है।
  • DataAdapter & DataSet: डेटाबेस और मेमोरी के बीच सेतु का काम करता है ताकि बिना लगातार कनेक्शन के डेटा ऑफलाइन प्रोसेस किया जा सके।

3. वास्तुकला एवं प्रवाह आरेख (Architecture & Flowchart Diagram)

ADO.NET की वास्तुकला और डेटा प्रवाह का आरेख नीचे दर्शाया गया है:

+---------------------------------------------------------+
|                  C# Application Layer                   |
+---------------------------------------------------------+
                             ↓
+---------------------------------------------------------+
|                  ADO.NET Data Providers                 |
|     [Connection] → [Command] → [DataReader / Adapter]   |
+---------------------------------------------------------+
                             ↓ (Disconnected / Connected)
+---------------------------------------------------------+
|                Database Server (SQL / MySQL)            |
+---------------------------------------------------------+

आरेख विवरण (Diagram Description): एप्लीकेशन लेयर से डेटा प्रोवाइडर (Connection और Command) के जरिए डेटाबेस से संपर्क किया जाता है, और DataReader या DataSet के माध्यम से डेटा प्राप्त होता है।

4. अनुप्रयोग (Applications)

ADO.NET का उपयोग निम्नलिखित क्षेत्रों में किया जाता है:

  • डेस्कटॉप और वेब एप्लिकेशनों में उपयोगकर्ता डेटा को सुरक्षित रूप से स्टोर और रिट्रीव करने में।
  • बैंकिंग और ई-कॉमर्स सॉफ्टवेयर में बड़े पैमाने पर ट्रांजैक्शन प्रबंधन के लिए।

5. लाभ, हानियां एवं सीमाएं (Pros, Cons & Limits)

### लाभ (Pros / Advantages):
  • डिसकनेक्टेड आर्किटेक्चर के कारण सर्वर पर लोड कम पड़ता है और नेटवर्क संसाधनों की बचत होती है।
  • यह विभिन्न प्रकार के डेटाबेस स्रोतों के साथ अत्यधिक अनुकूलनीय है।
### हानियां एवं सीमाएं (Cons & Limits):
  • कच्चे एसक्यूएल (Raw SQL queries) के साथ काम करते समय कोडिंग जटिल हो सकती है।

6. तुलना तालिका: DataReader बनाम DataSet (Comparison)

तुलनात्मक बिंदु DataReader (डेटा रीडर) DataSet (डेटासेट)
आर्किटेक्चर यह Connected Architecture पर आधारित है। यह Disconnected Architecture पर आधारित है।
डेटा प्रकृति केवल पढ़ने योग्य (Forward-only, Read-only)। मेमोरी में डेटा की पूरी कॉपी (Offline cacheable)।

7. प्रोग्रामिंग कोड उदाहरण (Code Snippet)

सी# भाषा में ADO.NET कनेक्शन और कमांड का एक संक्षिप्त उदाहरण नीचे प्रस्तुत है:

using System; using System.Data.SqlClient; class Program { static void Main(string[] args) { string connString = "Server=myServerAddress;Database=myDataBase;Trusted_Connection=True;"; using (SqlConnection conn = new SqlConnection(connString)) { try { conn.Open(); string query = "SELECT * FROM Users"; SqlCommand cmd = new SqlCommand(query, conn); SqlDataReader reader = cmd.ExecuteReader(); while (reader.Read()) { Console.WriteLine("User: " + reader["Username"].ToString()); } reader.Close(); } catch (Exception ex) { Console.WriteLine("त्रुटि: " + ex.Message); } } } }

इकाई II: मल्टीथ्रेडिंग और असिंक्रोनस प्रोग्रामिंग

बीसीए पंचम (V) सेमेस्टर • विषय: सीएएससी-14T (.NET Programming) • शत-प्रतिशत परीक्षा-उपयोगी विस्तृत नोट्स

1. परिचय एवं परिभाषा (Introduction & Definition)

सी# (C#) प्रोग्रामिंग में Multithreading (मल्टीथ्रेडिंग) एक ऐसा तंत्र है जिसके माध्यम से एक ही समय में एक प्रोग्राम के भीतर कई कार्यों (Threads) को स्वतंत्र रूप से निष्पादित किया जा सकता है। थ्रेड को "निष्पादन की सबसे छोटी इकाई" (Lightweight Process) माना जाता ਹੈ।

इसके साथ ही, Asynchronous Programming (असिंक्रोनस प्रोग्रामिंग), जिसे C# में async और await कीवर्ड के जरिए लागू किया जाता है, यूजर इंटरफेस को फ्रीज किए बिना लंबे समय तक चलने वाले कार्यों (जैसे डेटाबेस या नेटवर्क डाउनलोड) को पृष्ठभूमि में चलाने की अनुमति देती है।

2. मुख्य बिंदु एवं विशेषताएं (Key Points & Features)

  • थ्रेड (Thread): यह सीपीयू द्वारा संसाधित होने वाली निर्देशों की एक धारा (Stream of instructions) है।
  • Main Thread: प्रत्येक C# कंसोल या GUI एप्लीकेशन एक मुख्य थ्रेड से शुरू होती है।
  • Async / Await: यह आधुनिक .NET का वह मॉडल है जो बिना नए थ्रेड बनाए गैर-अवरोधक (Non-blocking) कोड लिखने में मदद करता है।
  • Thread Synchronization: कई थ्रेड जब एक ही संसाधन का उपयोग करते हैं, तो टकराव रोकने के लिए lock का उपयोग किया जाता है।

3. वास्तुकला एवं प्रवाह आरेख (Architecture & Flowchart Diagram)

सिंगल थ्रेडेड और मल्टीथ्रेडेड निष्पादन का प्रवाह आरेख नीचे दर्शाया गया है:

+---------------------------------------------------------+
|                Single-Threaded Execution                |
|       [Task 1] → [Task 2] → [Task 3] (क्रमबद्ध और धीमी)  |
+---------------------------------------------------------+

+---------------------------------------------------------+
|                Multi-Threaded Execution                 |
|       ├── [Thread 1] (Task A)                           |
|       ├── [Thread 2] (Task B)  (समांतर और तीव्र)        |
|       └── [Thread 3] (Task C)                           |
+---------------------------------------------------------+

आरेख विवरण (Diagram Description): सिंगल थ्रेड में कार्य एक के बाद एक होते हैं, जबकि मल्टीथ्रेडिंग में सीपीयू के विभिन्न कोर का उपयोग करके कई कार्य एक साथ (Parallel) चलाए जाते हैं।

4. अनुप्रयोग (Applications)

मल्टीथ्रेडिंग और असिंक्रोनस प्रोग्रामिंग का उपयोग निम्नलिखित क्षेत्रों में होता है:

  • बड़ी फाइलों को डाउनलोड या अपलोड करते समय यूजर इंटरफेस को चालू (Responsive) रखना।
  • सर्वर एप्लीकेशन (जैसे ASP.NET) में एक साथ हजारों यूजर्स के अनुरोधों को संभालना।

5. लाभ, हानियां एवं सीमाएं (Pros, Cons & Limits)

लाभ (Pros / Advantages):

  • सीपीयू संसाधनों का सर्वोत्तम उपयोग होता है और साफ्टवेयर की गति तेज हो जाती है।
  • यूजर इंटरफेस कभी भी 'Not Responding' की स्थिति में नहीं जाता।

हानियां एवं सीमाएं (Cons & Limits):

  • 'Deadlock' और 'Race Condition' जैसी समस्याएं आ सकती हैं यदि थ्रेड्स का सही प्रबंधन न किया जाए।
  • डिबग करना और त्रुटियों को खोजना थोड़ा जटिल होता है।

6. तुलना तालिका: Synchronous बनाम Asynchronous Programming (Comparison)

तुलनात्मक बिंदु सिंक्रोनस प्रोग्रामिंग (Synchronous) असिंक्रोनस प्रोग्रामिंग (Asynchronous)
कार्यप्रणाली कार्य एक के बाद एक लाइन से पूरे होते हैं (Blocking)। कार्य पृष्ठभूमि में चलते रहते हैं, रुकावट नहीं आती (Non-blocking)।
यूजर अनुभव लंबी प्रक्रिया के दौरान स्क्रीन फ्रीज हो सकती है। यूजर अन्य कार्य जारी रख सकता है।

7. प्रोग्रामिंग कोड उदाहरण (Code Snippet)

सी# भाषा में असिंक्रोनस मेथड (`async` और `await`) का एक संक्षिप्त उदाहरण नीचे प्रस्तुत है:

using System; using System.Threading.Tasks; class Program { static async Task Main(string[] args) { Console.WriteLine("डेटा डाउनलोड हो रहा है..."); string result = await DownloadDataAsync(); Console.WriteLine(result); } static async Task DownloadDataAsync() { await Task.Delay(2000); // 2 सेकंड का कृत्रिम विलंब return "डेटा सफलतापूर्वक डाउनलोड हो गया!"; } }

4. Practical Code Example (C# / VB.NET Data Types & Conversion)

Neeche ek code snippet diya gaya hai jo variables, type casting, aur operators ke use ko batata hai[span_5](start_span)[span_5](end_span):

// C# Example Demonstrating Data Types, Casting & Operators
using System;

namespace DataTypesDemo
{
    class Program
    {
        static void Main(string[] args)
        {
            Console.WriteLine("--- Data Types & Operators Demonstration ---");

            // Variables & Data Types
            int num1 = 45;
            int num2 = 10;

            // Arithmetic Operators
            int sum = num1 + num2;
            Console.WriteLine("Addition Result: " + sum);

            // Implicit Conversion (int to double)
            double convertedDouble = num1;
            Console.WriteLine("Implicit Conversion (int to double): " + convertedDouble);

            // Explicit Conversion / Casting (double to int)
            double highPrecValue = 99.99;
            int castedInt = (int)highPrecValue;
            Console.WriteLine("Explicit Casting (double to int): " + castedInt);

            Console.WriteLine("Data Types and operators executed successfully.");
            Console.ReadKey();
        }
    }
}

5. Pros (Labh / Advantages)

  • Type Safety: CTS aur strong typing ki wajah se runtime type mismatch errors kam hote hain[span_6](start_span)[span_6](end_span).
  • Flexible Operations: Operators aur casting ke zariye complex mathematical expressions easily solve kiye ja sakte hain.

6. Cons (Hani / Disadvantages)

  • Data Loss in Explicit Casting: Agar badi data type (double) ko choti data type (int) mein explicitly cast karein, toh decimal value lose ho sakti hai.

7. Limitations (Simitations / Badhayein)

  • Incompatible data types ke beech direct conversion nahi kiya ja sakta, uske liye Convert.ToInt32() ya parsing methods ka use karna padta hai.

इकाई III: टाइप्ड और अनटाइप्ड डेटासेट

बीसीए पंचम (V) सेमेस्टर • विषय: सीएएससी-14T (.NET Programming) • शत-प्रतिशत परीक्षा-उपयोगी विस्तृत नोट्स

1. परिचय एवं परिभाषा (Introduction & Definition)

ADO.NET में DataSet (डेटासेट) डिस्कनेक्टेड वास्तुकला (Disconnected Architecture) का मुख्य घटक है जो रैम (RAM) के भीतर डेटा की एक स्थानीय प्रति (In-memory cache) रखता है। डेटासेट मुख्य रूप से दो प्रकार के होते हैं: Untyped Dataset (अनटाइप्ड डेटासेट) और Typed Dataset (टाइप्ड डेटासेट)।

अनटाइप्ड डेटासेट में टेबल्स और कॉलम के नाम स्ट्रिंग के रूप में होते हैं जिनकी जाँच कम्पाइल-टाइम पर नहीं होती, जबकि टाइप्ड डेटासेट में XML स्कीमा (.xsd) के आधार पर एक मजबूत रूप से टाइप की गई (Strongly Typed) क्लास बनती है, जिससे डेटा त्रुटियां रन-टाइम से पहले ही पकड़ ली जाती हैं।

2. मुख्य बिंदु एवं विशेषताएं (Key Points & Features)

  • Untyped Dataset: यह सामान्य DataSet क्लास का उदाहरण है जिसमें डेटा को टेबल और कॉलम के इंडेक्स या नाम से एक्सेस किया जाता है (जैसे ds.Tables["Users"])।
  • Typed Dataset: यह DataSet से ही बनती है लेकिन इसके लिए विजुअल स्टूडियो एक कस्टम क्लास जनरेट करता है जिसमें सीधे प्रॉपर्टीज़ (जैसे row.UserName) मिलती हैं।
  • कम्पाइल-टाइम सुरक्षा: टाइप्ड डेटासेट में स्पेलिंग की गलती होने पर कम्पाइलर तुरंत त्रुटि बता देता है।

3. वास्तुकला एवं प्रवाह आरेख (Architecture & Flowchart Diagram)

टाइप्ड और अनटाइप्ड डेटासेट के निर्माण और उपयोग का प्रवाह आरेख नीचे दर्शाया गया है:

+---------------------------------------------------------+
|                  Database Schema / Tables               |
+---------------------------------------------------------+
             /                                   \
     (Untyped Approach)                 (Typed Approach)
           /                                       \
+-----------------------+               +-----------------------+
|  Standard DataSet     |               | XML Schema (.xsd)     |
| (Loose Typing / Name) |               | (Strongly Typed Class)|
+-----------------------+               +-----------------------+
           \                                       /
            v                                     v
+---------------------------------------------------------+
|                Application Code Access                  |
+---------------------------------------------------------+

आरेख विवरण (Diagram Description): अनटाइप्ड डेटासेट सीधे डेटाबेस स्ट्रक्चर को सामान्य नाम से एक्सेस करता है, जबकि टाइप्ड डेटासेट .xsd फाइल के जरिए मजबूत टाइपिंग और इंटेलिजेंस सपोर्ट प्रदान करता है।

4. अनुप्रयोग (Applications)

टाइप्ड और अनटाइप्ड डेटासेट का उपयोग निम्नलिखित क्षेत्रों में होता है:

  • जटिल एंटरप्राइज सॉफ्टवेयर में जहां डेटा की शुद्धता और ऑटो-कम्पलीट (IntelliSense) की आवश्यकता होती है।
  • ऑफ़लाइन डेटा कैशिंग और XML आधारित डेटा स्थानांतरण में।

5. लाभ, हानियां एवं सीमाएं (Pros, Cons & Limits)

लाभ (Pros / Advantages):

  • टाइप्ड डेटासेट में IntelliSense समर्थन मिलने से कोडिंग करना बहुत तेज और त्रुटि-मुक्त हो जाता है।
  • अनटाइप्ड डेटासेट अत्यधिक लचीला (Flexible) होता है क्योंकि इसका स्कीमा पहले से तय होना जरूरी नहीं है।

हानियां एवं सीमाएं (Cons & Limits):

  • टाइप्ड डेटासेट को सेट अप करने और स्कीमा फाइल (.xsd) प्रबंधित करने में अतिरिक्त मेहनत लगती है।

6. तुलना तालिका: Typed Dataset बनाम Untyped Dataset (Comparison)

तुलनात्मक बिंदु टाइप्ड डेटासेट (Typed Dataset) अनटाइप्ड डेटासेट (Untyped Dataset)
टाइप सुरक्षा (Type Safety) यह मजबूत टाइप-सेफ (Strongly typed) होता है। यह कमजोर रूप से टाइप (Loosely typed) होता है।
IntelliSense समर्थन विजुअल स्टूडियो में पूर्ण IntelliSense मिलता है। IntelliSense का समर्थन नहीं मिलता (नाम स्ट्रिंग में देने पड़ते हैं)।

7. प्रोग्रामिंग कोड उदाहरण (Code Snippet)

सी# भाषा में अनटाइप्ड डेटासेट का उपयोग करने का एक संक्षिप्त उदाहरण नीचे प्रस्तुत है:

using System; using System.Data; class Program { static void Main(string[] args) { DataSet ds = new DataSet("SchoolDB"); DataTable dt = new DataTable("Students"); dt.Columns.Add("ID", typeof(int)); dt.Columns.Add("Name", typeof(string)); dt.Rows.Add(1, "राहुल कुमार"); ds.Tables.Add(dt); // Untyped Access Console.WriteLine("छात्र का नाम: " + ds.Tables["Students"].Rows[0]["Name"]); } }

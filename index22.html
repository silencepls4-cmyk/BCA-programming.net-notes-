1. Complete Definition (Poori Paribhasha)

SqlCommand and SqlDataReader: SqlCommand ek aisi object hai jo database par SQL queries, statements, ya stored procedures ko execute karne ki shakti deti hai. SqlDataReader ek fast, forward-only stream provide karta hai jisse data ko row-by-row read kiya jata hai. DataGrid control is data ko user interface par tabular format mein display karta hai.

2. Architecture & Flowchart (Karya Pranali ka Flowchart)

Exam mein top score karne ke liye Command Execution aur Data Display ka yeh flowchart zaroor banayein:

SqlConnection (Open Connection)
↓
SqlCommand (ExecuteReader() / ExecuteNonQuery())
↓
SqlDataReader (Stream of Rows)
↓
DataGridView Control (Displaying Records in Rows & Columns)

3. Key Points & Component Breakdown

Command Method Vivaran / Description
ExecuteReader() SELECT queries ke liye use hota hai jo SqlDataReader return karta hai.
ExecuteNonQuery() INSERT, UPDATE, DELETE queries ke liye use hota hai (returns affected rows count).
ExecuteScalar() Single value return karne ke liye (jaise SELECT COUNT(*) FROM Students).

4. Practical Code Example (Command & DataReader in C#)

Neeche ek code snippet diya gaya hai jo SqlCommand aur DataReader ke use ko demonstrate karta hai:

// C# Example Demonstrating SqlCommand and SqlDataReader
using System;
using System.Data.SqlClient;
using System.Windows.Forms;

namespace CommandReaderDemo
{
    class Program
    {
        static void Main(string[] args)
        {
            Console.WriteLine("--- SqlCommand & DataReader Demo ---");

            string connString = "Server=myServer;Database=myDB;Trusted_Connection=True;";
            string query = "SELECT RollNo, StudentName FROM Students";

            using (SqlConnection conn = new SqlConnection(connString))
            {
                SqlCommand cmd = new SqlCommand(query, conn);
                try
                {
                    conn.Open();
                    SqlDataReader reader = cmd.ExecuteReader();

                    while (reader.Read())
                    {
                        Console.WriteLine("RollNo: " + reader["RollNo"] + " | Name: " + reader["StudentName"]);
                    }
                    reader.Close();
                }
                catch (Exception ex)
                {
                    Console.WriteLine("Error: " + ex.Message);
                }
            }

            Console.ReadKey();
        }
    }
}

5. Pros (Labh / Advantages)

  • Direct Control: SQL commands par poora control milta hai aur queries fast execute hoti hain.
  • Low Memory Usage: DataReader memory mein cache nahi karta, isliye memory efficient hai.

6. Cons (Hani / Disadvantages)

  • Active Connection Needed: Data read karte waqt database connection poori der open rakhna padta hai.

7. Limitations (Simitations / Badhayein)

  • DataReader se data sirf ek hi direction (forward) mein read kiya ja sakta hai, pichle records par wapas nahi ja sakte.

8. Real-World Applications (Upyog / Use Cases)

  • User login authentication, fast reports generation, aur real-time data inspection mein.

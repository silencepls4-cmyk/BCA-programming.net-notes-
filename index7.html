1. Complete Definitions (Poori Paribhasha)

CLS (Common Language Specification): Yeh rules aur guidelines ka ek standard set hai jo yeh ensure karta hai ki alag-alag languages (jaise C# aur VB.NET) mein likhe gaye components aapas mein seamlessly communicate kar sakein[span_1](start_span)[span_1](end_span).

BCL & FCL (Base Class Library / Framework Class Library): Yeh pre-written classes, namespaces, aur methods ka ek vishal sangrah hai jo developers ko file handling, database connection, aur UI design karne ke liye ready-made code provide karta hai[span_2](start_span)[span_2](end_span).

Garbage Collection (GC): Yeh CLR ka ek automatic memory management subsystem hai jo memory heap se unallocated objects ko automatically destroy karke memory free karta hai.

4. Practical Code Example (Explicit Garbage Collection Control)

Neeche ek code snippet diya gaya hai jo GC methods aur memory management ko demonstrate karta hai[span_4](start_span)[span_4](end_span):

// C# Example Demonstrating Garbage Collection & Memory Diagnostics
using System;

namespace AdvancedUnit1Demo
{
    class Program
    {
        static void Main(string[] args)
        {
            Console.WriteLine("--- Advanced CLR Garbage Collection Demo ---");
            
            // Memory allocated before creating objects
            long initialMemory = GC.GetTotalMemory(false);
            Console.WriteLine("Initial Memory: " + initialMemory + " bytes");
            
            // Creating temporary objects
            for (int i = 0; i < 10000; i++)
            {
                string tempObj = "Memory Test Object " + i;
            }
            
            // Forcing Garbage Collection explicitly (For demonstration purposes)
            GC.Collect();
            GC.WaitForPendingFinalizers();
            
            long finalMemory = GC.GetTotalMemory(true);
            Console.WriteLine("Memory after Garbage Collection: " + finalMemory + " bytes");
            
            Console.WriteLine("Advanced Unit I concepts executed successfully.");
            Console.ReadKey();
        }
    }
}

5. Pros (Labh / Advantages)

  • No Manual Memory Management: C/C++ ki tarah malloc ya free likhne ki jaroorat nahi padti[span_5](start_span)[span_5](end_span).
  • Language Interoperability: CLS ki wajah se multi-language development team mein koi conflict nahi hota[span_6](start_span)[span_6](end_span).
  • Rapid Development: BCL ke thousands of classes se coding time 70% tak bach jata hai[span_7](start_span)[span_7](end_span).

6. Cons (Hani / Disadvantages)

  • GC Pause / Latency: Jab Garbage Collector heavy memory clean karta hai, tab application mein micro-stutter ya pause aa sakta hai.
  • Strict Rules: CLS-compliant code likhte samay kuch data types aur naming conventions par restrictions hoti hain.

7. Limitations (Simitations / Badhayein)

  • Unmanaged resources (jaise file handles, database connections, ya window handles) ko Garbage Collector khud clean nahi kar sakta, unke liye Dispose() method likhna padta hai.

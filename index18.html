इकाई II: अपवाद प्रबंधन (Exception Handling in C#)

बीसीए पंचम (V) सेमेस्टर • विषय: सीएएससी-14T (.NET Programming) • शत-प्रतिशत परीक्षा-उपयोगी विस्तृत नोट्स

1. परिचय एवं परिभाषा (Introduction & Definition)

सी# (C#) प्रोग्रामिंग में Exception Handling (अपवाद प्रबंधन) एक ऐसा मजबूत तंत्र है जो प्रोग्राम के निष्पादन के दौरान आने वाली अप्रत्याशित त्रुटियों (Run-time Errors) को नियंत्रित और प्रबंधित करता है। जब साफ्टवेयर चलते समय किसी समस्या (जैसे किसी संख्या को शून्य से भाग देना या मौजूद न होने वाली फाइल खोलना) का सामना करता है, तो प्रोग्राम अचानक क्रैश होने के बजाय एक अपवाद (Exception) उत्पन्न करता है।

अपवाद प्रबंधन के माध्यम से डेवलपर उस त्रुटि को पकड़कर यूजर को एक सुरक्षित संदेश दिखा सकता है और साफ्टवेयर के सामान्य प्रवाह को टूटने से बचा सकता है।

2. मुख्य बिंदु एवं मुख्य कीवर्ड (Key Points & Keywords)

  • try ब्लॉक: इस ब्लॉक के अंदर वह कोड लिखा जाता है जिसमें त्रुटि आने की संभावना होती है।
  • catch ब्लॉक: यदि try ब्लॉक में कोई त्रुटि आती है, तो catch ब्लॉक उसे पकड़कर संभालता है (Handle करता है)।
  • finally ब्लॉक: यह ब्लॉक त्रुटि आए या न आए, हमेशा निष्पादित होता है (जैसे डेटाबेस कनेक्शन बंद करना)।
  • throw कीवर्ड: इसके जरिए स्वेच्छा से एक नया अपवाद उत्पन्न किया जा सकता है।

3. वास्तुकला एवं प्रवाह आरेख (Architecture & Flowchart Diagram)

try, catch और finally ब्लॉक की कार्यप्रणाली का प्रवाह आरेख नीचे दर्शाया गया है:

+---------------------------------------------------------+
|                    Start Try Block                      |
+---------------------------------------------------------+
                             ↓
          [क्या रनटाइम पर कोई त्रुटि (Exception) आई?]
                     /                  \
              (हाँ / Yes)            (नहीं / No)
                 /                          \
+-------------------------------+  +--------------------------+
|      Execute Catch Block      |  |  Skip Catch Block        |
+-------------------------------+  +--------------------------+
                 \                          /
                  v                        v
+---------------------------------------------------------+
|                   Execute Finally Block                 |
|             (संसाधन मुक्त करना और सामान्य प्रवाह)         |
+---------------------------------------------------------+

आरेख विवरण (Diagram Description): ट्राई ब्लॉक में कोड चलता है। यदि त्रुटि आती है तो कैच ब्लॉक उसे संभालता है, और अंत में फाइनली ब्लॉक हमेशा निष्पादित होकर संसाधनों को साफ करता है।

4. अनुप्रयोग (Applications)

अपवाद प्रबंधन का उपयोग निम्नलिखित क्षेत्रों में किया जाता है:

  • फाइल इनपुट-आउटपुट (File I/O) संचालन में जहाँ फाइल अनुपलब्ध हो सकती है।
  • डेटाबेस कनेक्टिविटी और नेटवर्क अनुरोधों के दौरान उत्पन्न होने वाली बाधाओं को दूर करने में।

5. लाभ, हानियां एवं सीमाएं (Pros, Cons & Limits)

### लाभ (Pros / Advantages):
  • अचानक प्रोग्राम क्रैश होने से बच जाता है और यूजर को बेहतर अनुभव मिलता है।
  • त्रुटि की सटीक जानकारी डिबगिंग के दौरान मिल जाती है।
### हानियां एवं सीमाएं (Cons & Limits):
  • अत्यधिक मात्रा में try-catch ब्लॉक का उपयोग करने से प्रोग्राम की गति (Performance) पर थोड़ा प्रभाव पड़ सकता है।

6. तुलना तालिका: Compile-time Error बनाम Run-time Exception (Comparison)

तुलनात्मक बिंदु कम्पाइल-टाइम एरर (Compile-time Error) रन-टाइम अपवाद (Run-time Exception)
उत्पन्न होने का समय प्रोग्राम को कंपाइल करते समय (जैसे सिंटैक्स की गलती)। प्रोग्राम के चलते समय (जैसे शून्य से भाग देना)।
नियंत्रण इसे कोड ठीक करके तुरंत सुधारा जाता है। इसे Exception Handling (try-catch) से प्रबंधित किया जाता है।

7. प्रोग्रामिंग कोड उदाहरण (Code Snippet)

सी# भाषा में अपवाद प्रबंधन (Try-Catch-Finally) का एक संक्षिप्त उदाहरण नीचे प्रस्तुत है:

using System; class Program { static void Main(string[] args) { try { int a = 10, b = 0; int c = a / b; // यहाँ DivideByZeroException आएगा Console.WriteLine("Result: " + c); } catch (DivideByZeroException ex) { Console.WriteLine("त्रुटि आई: शून्य से भाग देना संभव नहीं है!"); } finally { Console.WriteLine("Finally ब्लॉक हमेशा चलता है।"); } } }

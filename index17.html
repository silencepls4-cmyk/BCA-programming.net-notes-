इकाई II: एब्स्ट्रैक्ट क्लासेज और इंटरफेस (Abstract Classes & Interfaces)

बीसीए पंचम (V) सेमेस्टर • विषय: सीएएससी-14T (.NET Programming) • शत-प्रतिशत परीक्षा-उपयोगी विस्तृत नोट्स

1. परिचय एवं परिभाषा (Introduction & Definition)

सी# (C#) प्रोग्रामिंग में Abstract Class (एब्स्ट्रैक्ट क्लास) एक ऐसी विशेष क्लास होती है जिसका उपयोग केवल अन्य कक्षाओं के लिए एक बेस (Base) या ब्लूप्रिंट के रूप में किया जाता है। इसका सीधे तौर पर ऑब्जेक्ट (Object) नहीं बनाया जा सकता है। इसे बनाने के लिए abstract कीवर्ड का उपयोग होता है।

दूसरी ओर, Interface (इंटरफेस) एक ऐसा अनुबंध (Contract) है जिसमें केवल मेथड, प्रॉपर्टीज और इवेंट्स की घोषणा (Declaration) होती है, लेकिन उनका शरीर (Body/Implementation) नहीं होता। इंटरफेस के माध्यम से C# में बहु-इन्हेरिटेंस (Multiple Inheritance) की कमी को पूरा किया जाता है।

2. मुख्य बिंदु एवं विशेषताएं (Key Points & Features)

  • एब्स्ट्रैक्ट क्लास विशेषता: इसमें एब्स्ट्रैक्ट (बिना बॉडी के) और नॉन-एब्स्ट्रैक्ट (बॉडी सहित) दोनों प्रकार की मेथड्स हो सकती हैं।
  • इंटरफेस विशेषता: इंटरफेस के सभी सदस्य बाय डिफॉल्ट `public` और `abstract` होते हैं। इसमें फील्ड्स (Variables) नहीं बनाए जा सकते।
  • अनुपालन (Implementation): जो क्लास किसी इंटरफेस को लागू (Implement) करती है, उसे उसके सभी सदस्यों को लिखना अनिवार्य होता है।

3. वास्तुकला एवं प्रवाह आरेख (Architecture & Flowchart Diagram)

एब्स्ट्रैक्ट क्लास और इंटरफेस के माध्यम से पदानुक्रम और कार्यान्वयन का प्रवाह आरेख नीचे दर्शाया गया है:

+---------------------------------------------------------+
|                Abstract Class / Interface               |
|      (केवल अनुबंध और नियम तय करते हैं - No Direct Object) |
+---------------------------------------------------------+
                             ↓ (Implementation / Inheritance)
+---------------------------------------------------------+
|                  Derived / Child Class                  |
|          (नियमों का पालन करती है और वास्तविक कोड लिखती है) |
+---------------------------------------------------------+
                             ↓
+---------------------------------------------------------+
|                   Object Instantiation                  |
+---------------------------------------------------------+

आरेख विवरण (Diagram Description): एब्स्ट्रैक्ट क्लास या इंटरफेस केवल ढांचा तैयार करते हैं, और वास्तविक कोड डिराइव्ड क्लास के अंदर लिखकर ऑब्जेक्ट तैयार किया जाता है।

4. अनुप्रयोग (Applications)

एब्स्ट्रैक्ट क्लास और इंटरफेस का उपयोग निम्नलिखित क्षेत्रों में किया जाता है:

  • मानकीकृत सॉफ्टवेयर आर्किटेक्चर और प्लग-इन सिस्टम के विकास में।
  • विभिन्न डेवलपर टीमों के बीच एक निश्चित कोडिंग अनुबंध (Contract) तय करने में।

5. लाभ, हानियां एवं सीमाएं (Pros, Cons & Limits)

लाभ (Pros / Advantages):

  • लूस कपलिंग (Loose Coupling) को बढ़ावा मिलता है जिससे साफ्टवेयर अधिक लचीला बनता है।
  • इंटरफेस के जरिए C# में मल्टीपल इन्हेरिटेंस जैसी सुविधा मिलती है।

हानियां एवं सीमाएं (Cons & Limits):

  • एब्स्ट्रैक्ट क्लास का सीधे ऑब्जेक्ट नहीं बनाया जा सकता।
  • इंटरफेस में यदि कोई नया मेथड जोड़ा जाए, तो उससे जुड़ी सभी कक्षाओं में बदलाव करना पड़ता है।

6. तुलना तालिका: Abstract Class बनाम Interface (Comparison)

तुलनात्मक बिंदु Abstract Class (एब्स्ट्रैक्ट क्लास) Interface (इंटरफेस)
मेथड बॉडी इसमें एब्स्ट्रैक्ट और सामान्य दोनों विधियाँ हो सकती हैं। इसमें केवल विधियों की घोषणा होती है (बॉडी नहीं)।
इन्हेरिटेंस यह केवल एक एब्स्ट्रैक्ट क्लास को इन्हेरिट कर सकता है। यह एकाधिक (Multiple) इंटरफेस को लागू कर सकता है।
वेरिएबल/फील्ड्स यह इंस्टेंस वेरिएबल्स रख सकता है। यह फील्ड्स या वेरिएबल्स नहीं रख सकता।

7. प्रोग्रामिंग कोड उदाहरण (Code Snippet)

सी# भाषा में एब्स्ट्रैक्ट क्लास और इंटरफेस का एक संक्षिप्त उदाहरण नीचे प्रस्तुत है:

using System; // Interface Definition interface IAnimal { void Sound(); } // Abstract Class Definition abstract class Animal : IAnimal { public abstract void Sound(); // Abstract Method public void Sleep() { Console.WriteLine("Animal is sleeping..."); } } // Derived Class class Dog : Animal { public override void Sound() { Console.WriteLine("Dog barks: Bhou Bhou"); } }

1. Complete Definition (Poori Paribhasha)

Methods, Sub Procedures, and Functions: Method code ka ek organized block hota hai jo ek specific task perform karta hai. .NET mein yeh do mukhya roop mein hote hain: **Sub Procedures** (jo actions perform karte hain par koi value return nahi karte, C# mein `void` methods ke roop mein jaane jate hain) aur **Functions** (jo calculation ya processing ke baad ek definite value return karte hain).

2. Architecture & Flowchart (Karya Pranali ka Flowchart)

Exam mein top score karne ke liye Method Call aur Return flow ka yeh flowchart zaroor banayein:

Main Program Execution
↓
Method Call with Arguments (Passing Data)
┌───────────────┴───────────────┐
Sub Procedure (Executes actions, returns no value)
Function (Processes data & returns a value via 'return')

3. Key Points & Component Breakdown

Method Type Vivaran / Description
Sub Procedure Aise blocks jo actions execute karte hain par result wapas nahi bhejte (VB.NET mein Sub, C# mein void).
Function Aise blocks jo computation karte hain aur ek data type value return karte hain (VB.NET mein Function, C# mein return type wala method).
Parameters & Arguments Methods ke beech data pass karne ke liye variables jo parenthesis ke andar define kiye jate hain.

4. Practical Code Example (Sub Procedures and Functions in C#)

Neeche ek code snippet diya gaya hai jo Sub procedure aur Function ke use ko demonstrate karta hai:

// C# Example Demonstrating Sub Procedures (Void Methods) and Functions
using System;

namespace MethodsAndProceduresDemo
{
    class Program
    {
        // 1. Sub Procedure equivalent (Void method - Returns no value)
        static void PrintHeader(string title)
        {
            Console.WriteLine("================================");
            Console.WriteLine("  " + title);
            Console.WriteLine("================================");
        }

        // 2. Function equivalent (Returns an integer value)
        static int MultiplyNumbers(int a, int b)
        {
            return a * b;
        }

        static void Main(string[] args)
        {
            // Calling Sub Procedure
            PrintHeader("CASC-14T Methods Demo");

            // Calling Function and storing returned result
            int result = MultiplyNumbers(6, 7);
            Console.WriteLine("Multiplication Result from Function: " + result);

            Console.ReadKey();
        }
    }
}

5. Pros (Labh / Advantages)

  • Code Reusability: Ek baar method likh kar use program mein multiple times call kiya ja sakta hai.
  • Maintainability: Bade code ko chote, manageable blocks mein divide karne se debugging asan ho jati hai.

6. Cons (Hani / Disadvantages)

  • Overhead: Har method call ke dauran stack memory par frame allocation ka minor overhead hota hai.

7. Limitations (Simitations / Badhayein)

  • Agar method ke andar bahut sare parameters pass kiye jayein, toh code ki complexity badh jati hai.

8. Real-World Applications (Upyog / Use Cases)

  • Mathematical calculations, data validation, aur modular software architecture banane mein.

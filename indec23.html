इकाई III: MDI फॉर्म्स, मेन्यू और डायलॉग बॉक्स

बीसीए पंचम (V) सेमेस्टर • विषय: सीएएससी-14T (.NET Programming) • शत-प्रतिशत परीक्षा-उपयोगी विस्तृत नोट्स

1. परिचय एवं परिभाषा (Introduction & Definition)

विंडोज फॉर्म्स एप्लीकेशन में MDI (Multiple Document Interface - बहु-दस्तावेज़ इंटरफेस) एक ऐसा डिज़ाइन पैटर्न है जिसमें एक मुख्य पेरेंट विंडो (Parent Window) के भीतर कई छोटे चाइल्ड फॉर्म्स (Child Forms) एक साथ खुले रह सकते हैं (जैसे MS Word या Excel जिसमें एक साथ कई फाइलें खुलती हैं)।

इसके साथ ही, MenuStrip (मेन्यू) यूजर को सॉफ्टवेयर के विभिन्न विकल्पों तक पहुँचने की सुविधा देता है, और Dialog Boxes (डायलॉग बॉक्स जैसे OpenFileDialog, SaveFileDialog) यूजर से फाइल चयन या संदेश आदान-प्रदान करने का मानक माध्यम प्रदान करते हैं।

2. मुख्य बिंदु एवं विशेषताएं (Key Points & Features)

  • MDI Parent & Child: पेरेंट फॉर्म मुख्य कंटेनर होता है और चाइल्ड फॉर्म्स उसी के दायरे के अंदर तैरते (Float) हैं।
  • MenuStrip: यह फॉर्म के ऊपर फाइल, एडिट, हेल्प जैसे ड्रॉप-डाउन मेनू बनाने के लिए उपयोग होता है।
  • Common Dialogs: फाइल खोलना, सहेजना, रंग या फॉंट बदलना आदि के लिए पहले से बने डायलॉग बॉक्सेस का उपयोग।

MDI पेरेंट और चाइल्ड फॉर्म्स की पदानुक्रमित संरचना का प्रवाह आरेख नीचे दर्शाया गया है:

आरेख विवरण (Diagram Description): मुख्य MDI पेरेंट फॉर्म के भीतर एकाधिक चाइल्ड फॉर्म्स और मेन्यू बार एक साथ नियंत्रित होते हैं, जिससे स्क्रीन प्रबंधन आसान हो जाता है।

4. अनुप्रयोग (Applications)

MDI फॉर्म्स और डायलॉग बॉक्स का उपयोग निम्नलिखित क्षेत्रों में होता है:

  • टेक्स्ट एडिटर्स, ग्राफिक डिजाइनिंग टूल्स और मल्टी-डॉक्यूमेंट सॉफ्टवेयर के निर्माण में।
  • फाइल मैनेजमेंट सिस्टम में यूजर से इनपुट लेने और फाइलें सहेजने के लिए।

5. लाभ, हानियां एवं सीमाएं (Pros, Cons & Limits)

लाभ (Pros / Advantages):

  • एक ही मुख्य विंडो के अंदर कई विंडो को आसानी से प्रबंधित किया जा सकता है।
  • स्क्रीन स्पेस का बेहतर उपयोग होता है और टास्कबार अव्यवस्थित नहीं होता।

हानियां एवं सीमाएं (Cons & Limits):

  • मोबाइल या छोटी स्क्रीन वाले उपकरणों के लिए MDI डिज़ाइन उपयुक्त नहीं माना जाता।

6. तुलना तालिका: SDI बनाम MDI फॉर्म्स (Comparison)

तुलनात्मक बिंदु SDI (Single Document Interface) MDI (Multiple Document Interface)
विंडो संरचना प्रत्येक दस्तावेज के लिए एक स्वतंत्र नई विंडो खुलती है। एक मुख्य पेरेंट विंडो के भीतर कई चाइल्ड विंडो खुलती हैं।
संसाधन प्रबंधन एकाधिक विंडो होने पर टास्कबार भर जाता है। सभी चाइल्ड विंडो मुख्य पेरेंट के अंदर ब बंधी रहती हैं।

7. प्रोग्रामिंग कोड उदाहरण (Code Snippet)

सी# भाषा में MDI पेरेंट फॉर्म के अंदर चाइल्ड फॉर्म खोलने का एक संक्षिप्त उदाहरण नीचे प्रस्तुत है:

using System; using System.Windows.Forms; public class MainForm : Form { public MainForm() { this.IsMdiContainer = true; // इसे MDI Parent बनाया गया Button btnOpenChild = new Button() { Text = "नया चाइल्ड खोलें", Location = new System.Drawing.Point(20, 20) }; btnOpenChild.Click += (sender, e) => { Form childForm = new Form(); childForm.Text = "चाइल्ड विंडो"; childForm.MdiParent = this; childForm.Show(); }; this.Controls.Add(btnOpenChild); } public static void Main() { Application.Run(new MainForm()); } }

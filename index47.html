प्रैक्टिकल 1: C# में इनहेरिटेंस (Inheritance) का लाइव कोड और टेस्टिंग

यह प्रैक्टिकल दर्शाता है कि कैसे एक बेस क्लास के गुणों को डिराइव्ड क्लास में पुन: उपयोग (Reuse) किया जाता है:

using System; // बेस क्लास (Parent Class) class Animal { public string name; public void Eat() { Console.WriteLine(name + " खाना खा रहा है।"); } } // डिराइव्ड क्लास (Child Class) class Dog : Animal { public void Bark() { Console.WriteLine(name + " भोंक रहा है: भौं-भौं!"); } } class TestProgram { static void Main() { Dog myDog = new Dog(); myDog.name = "टॉमी"; myDog.Eat(); // बेस क्लास का मेथड myDog.Bark(); // डिराइव्ड क्लास का मेथड } }
अपेक्षित आउटपुट (Expected Output):
टॉमी खाना खा रहा है।
टॉमी भोंक रहा है: भौं-भौं!

प्रैक्टिकल 2: अपवाद हैंडलिंग (Try-Catch-Finally) का लाइव कोड

रन-टाइम एरर को संभालने और प्रोग्राम को क्रैश होने से बचाने के लिए नीचे दिए गए कोड का परीक्षण किया जाता है:

using System; class ExceptionTest { static void Main() { try { int a = 20, b = 0; int result = a / b; // यहाँ DivideByZeroException आएगा Console.WriteLine("परिणाम: " + result); } catch (DivideByZeroException ex) { Console.WriteLine("त्रुटि पकड़ी गई: किसी भी संख्या को शून्य से विभाजित नहीं किया जा सकता!"); } finally { Console.WriteLine("फाइनली ब्लॉक: यह कोड हमेशा निष्पादित होता है।"); } } }
अपेक्षित आउटपुट (Expected Output):
त्रुटि पकड़ी गई: किसी भी संख्या को शून्य से विभाजित नहीं किया जा सकता!
फाइनली ब्लॉक: यह कोड हमेशा निष्पादित होता है।

प्रैक्टिकल 3: ADO.NET डेटासेट और डेटाडाप्टर का उपयोग

डेटाबेस से डिस्कनेक्टेड मोड में डेटा लाने और ग्रिडव्यू में बाइंड करने का मानक कोड:

using System; using System.Data; using System.Data.SqlClient; class AdoNetPractical { static void Main() { string connString = "Data Source=server;Initial Catalog=SchoolDB;Integrated Security=true;"; string query = "SELECT * FROM Students"; using (SqlConnection conn = new SqlConnection(connString)) { SqlDataAdapter da = new SqlDataAdapter(query, conn); DataSet ds = new DataSet(); da.Fill(ds, "StudentsTable"); Console.WriteLine("डेटाबेस से कुल पंक्तियाँ लोड हुईं: " + ds.Tables["StudentsTable"].Rows.Count); } } }
अपेक्षित आउटपुट (Expected Output):
डेटाबेस से कुल पंक्तियाँ लोड हुईं: 15 (डेटाबेस के अनुसार)

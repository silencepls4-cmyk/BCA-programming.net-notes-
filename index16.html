4. Practical Code Example (Arrays in C# / VB.NET)

Neeche ek code snippet diya gaya hai jo 1D, 2D, aur Jagged arrays ke use ko demonstrate karta hai[span_6](start_span)[span_6](end_span):

// C# Example Demonstrating 1D, 2D, and Jagged Arrays
using System;

namespace ArraysDemo
{
    class Program
    {
        static void Main(string[] args)
        {
            Console.WriteLine("--- Arrays Standalone Demo ---");

            // 1. One-Dimensional (1D) Array
            int[] numbers = { 10, 20, 30, 40, 50 };
            Console.WriteLine("1D Array Element at index 2: " + numbers[2]);

            // 2. Two-Dimensional (2D) Array (Matrix)
            int[,] matrix = {
                { 1, 2 },
                { 3, 4 }
            };
            Console.WriteLine("2D Array element at [0,1]: " + matrix[0, 1]);

            // 3. Jagged Array (Array of Arrays)
            int[][] jaggedArray = new int[2][];
            jaggedArray[0] = new int[] { 1, 2, 3 };
            jaggedArray[1] = new int[] { 4, 5 };
            Console.WriteLine("Jagged Array [1][0]: " + jaggedArray[1][0]);

            Console.ReadKey();
        }
    }
}

5. Pros (Labh / Advantages)

  • Fast Data Access: Index ke zariye kisi bhi element ko O(1) time complexity mein direct access kiya ja sakta hai[span_7](start_span)[span_7](end_span).
  • Organized Structure: Related data ko ek sath memory mein neatly store karta hai[span_8](start_span)[span_8](end_span).

6. Cons (Hani / Disadvantages)

  • Fixed Size: Standard arrays ki size static hoti hai; ek baar declare hone ke baad runtime par unka size badhaya nahi ja sakta.

7. Limitations (Simitations / Badhayein)

  • Agar array mein extra elements insert karne hon, toh naya bada array bana kar data copy karna padta hai jo inefficient hota hai.

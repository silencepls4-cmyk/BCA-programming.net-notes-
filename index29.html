इकाई III (शेष टॉपिक): डेटा अडैप्टर, Fill और Update विधियाँ

बीसीए पंचम (V) सेमेस्टर • विषय: सीएएससी-14T (.NET Programming) • शत-प्रतिशत परीक्षा-उपयोगी विस्तृत नोट्स

1. परिचय एवं परिभाषा (Introduction & Definition)

ADO.NET के डिस्कनेक्टेड आर्किटेक्चर (Disconnected Architecture) में SqlDataAdapter एक महत्वपूर्ण सेतु (Bridge) का काम करता है। यह डेटाबेस और इन-मेमोरी DataSet या DataTable के बीच डेटा का आदान-प्रदान करता है।

डेटा अडैप्टर की दो सबसे प्रमुख विधियाँ Fill() और Update() हैं। Fill() विधि डेटाबेस से डेटा निकालकर डेटासेट को भरती है, जबकि Update() विधि डेटासेट में किए गए बदलावों (जैसे नए रिकॉर्ड जोड़ना या पुराने बदलना) को वापस मूल डेटाबेस तक पहुँचाती है।

2. मुख्य बिंदु एवं विधियाँ (Key Points & Methods)

  • Fill() मेथड: यह डेटाबेस से SELECT क्वेरी चलाकर डेटा प्राप्त करती है और उसे डेटासेट या डेटाटेबल में लोड करती है।
  • Update() मेथड: यह डेटासेट के रो (Rows) की स्थिति (RowState - Added, Modified, Deleted) की जांच करती है और तदनुसार डेटाबेस में बदलाव लागू करती है।
  • Command Objects: डेटा अडैप्टर के भीतर SelectCommand, InsertCommand, UpdateCommand और DeleteCommand जैसी चार कमांड्स होती हैं।

3. वास्तुकला एवं प्रवाह आरेख (Architecture & Flowchart Diagram)

डेटा अडैप्टर की Fill और Update प्रक्रिया का प्रवाह आरेख नीचे दर्शाया गया है:

+---------------------------------------------------------+
|                  Database Server                        |
+---------------------------------------------------------+
       ↑ (Update Method - Changes Sent Back)   | (Fill Method - Data Loaded)
       |                                       v
+---------------------------------------------------------+
|                    SqlDataAdapter                       |
+---------------------------------------------------------+
       |                                       ↑
       v (Populates In-Memory Cache)           | (Sends Modified Data)
+---------------------------------------------------------+
|                  DataSet / DataTable                    |
+---------------------------------------------------------+

आरेख विवरण (Diagram Description): Fill मेथड डेटाबेस से डेटा खींचकर DataSet में रखती है, और Update मेथड DataSet के संशोधित डेटा को वापस डेटाबेस सर्वर पर सुरक्षित करती है।

4. अनुप्रयोग (Applications)

इन विधियों का उपयोग निम्नलिखित क्षेत्रों में होता है:

  • ऑफ़लाइन डेटा प्रविष्टि और बैच अपडेट (Batch Updates) प्रणालियों में।
  • जब एक साथ हजारों रिकॉर्ड्स को लोड करके स्थानीय स्तर पर संशोधित करना हो।

5. लाभ, हानियां एवं सीमाएं (Pros, Cons & Limits)

### लाभ (Pros / Advantages):
  • लगातार डेटाबेस कनेक्शन खुला रखने की आवश्यकता नहीं होती, जिससे सर्वर सुरक्षित रहता है।
  • एक ही बार में पूरे टेबल का डेटा लोड करके स्थानीय रूप से काम किया जा सकता है।
### हानियां एवं सीमाएं (Cons & Limits):
  • यदि डेटाबेस में किसी अन्य यूजर ने एक ही समय में डेटा बदल दिया है, तो कॉन्फ्लिक्ट (Concurrency Conflict) आ सकता है।

6. तुलना तालिका: Fill() बनाम Update() मेथड (Comparison)

तुलनात्मक बिंदु Fill() मेथड Update() मेथड
दिशायुग्म (Direction) डेटाबेस से डेटा **डेटासेट (Dataset)** की ओर आता है। डेटासेट से संशोधित डेटा **डेटाबेस** की ओर जाता है।
मुख्य उपयोग डेटा को स्क्रीन पर दिखाने के लिए लोड करना। यूजर द्वारा किए गए बदलावों को डेटाबेस में सहेजना।

7. प्रोग्रामिंग कोड उदाहरण (Code Snippet)

सी# भाषा में DataAdapter के जरिए Fill और Update करने का संक्षिप्त उदाहरण:

using System; using System.Data; using System.Data.SqlClient; class AdapterExample { static void Main(string[] args) { string connStr = "Server=myServerAddress;Database=myDataBase;Trusted_Connection=True;"; using (SqlConnection conn = new SqlConnection(connStr)) { SqlDataAdapter da = new SqlDataAdapter("SELECT * FROM Employees", conn); SqlCommandBuilder cb = new SqlCommandBuilder(da); // स्वचालित कमांड जनरेट करता है DataSet ds = new DataSet(); da.Fill(ds, "Employees"); // डेटा लोड करना (Fill) // डेटा में बदलाव करने के बाद... // da.Update(ds, "Employees"); // डेटाबेस में वापस भेजना (Update) Console.WriteLine("डेटा अडैप्टर Fill और Update प्रक्रिया सफलतापूर्वक समझी गई।"); } } }

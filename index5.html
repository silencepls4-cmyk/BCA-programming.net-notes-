Unit I - Topic 5: Namespace, Metadata, and Common Type System (CTS)

BCA Semester-V • 100% Exam Quality Notes (Hindi)

1. Complete Definitions (Poori Paribhasha)

Namespace: Yeh ek logical grouping mechanism hai jo related classes, interfaces, aur structures ko ek hi container ke andar organize karta hai taaki naming conflicts (jaise ek hi naam ke do classes hona) na ho[span_1](start_span)[span_1](end_span).

Metadata: Yeh data-about-data hai jo assembly ke andar store hota hai. Isme bataya jata hai ki code mein kaun se types, methods, aur properties hain taaki CLR bina header files ke code ko safely execute kar sake.

Common Type System (CTS): Yeh .NET ka ek universal standard hai jo define karta hai ki .NET languages (jaise C# aur VB.NET) mein data types kaise declare, use, aur memory mein represent kiye jayenge[span_2](start_span)[span_2](end_span).

2. Architecture & Flowchart (100% Exam Marks Diagram)

3. Key Points & Component Breakdown

Component / Concept Detailed Description (Vivaran)
Value Types Yeh direct data ko Stack memory mein store karte hain (jaise Integer, Boolean, Float, Structs).
Reference Types Yeh object ka reference Heap memory mein store karte hain (jaise Classes, Strings, Arrays).
Namespaces Code ko hierarchical structure mein divide karte hain (jaise System.Windows.Forms)[span_3](start_span)[span_3](end_span).
Metadata Tables Classes, methods, fields, aur attributes ki poori jankari binary format mein rakhte hain.

4. Practical Code Example (Namespace & CTS Usage)

Neeche ek code snippet diya gaya hai jo Namespaces aur CTS data types ke use ko batata hai[span_4](start_span)[span_4](end_span):

// C# Example Demonstrating Namespaces and CTS Types
using System; // System namespace ka use

namespace NamespaceDemoApp
{
    class Program
    {
        static void Main(string[] args)
        {
            // CTS Value Type
            Int32 age = 21; // System.Int32 maps to int in C#
            
            // CTS Reference Type
            String studentName = "Priya"; // System.String maps to string
            
            Console.WriteLine("Student Name (Reference Type): " + studentName);
            Console.WriteLine("Age (Value Type System.Int32): " + age);
            
            Console.WriteLine("Namespaces and CTS executed successfully.");
            Console.ReadKey();
        }
    }
}

5. Pros (Labh / Advantages)

  • No Name Collisions: Namespaces ki wajah se bade projects mein duplicate class names ki problem nahi hoti.
  • Cross-Language Type Consistency: CTS ki wajah se C# ka int aur VB.NET ka Integer aapas mein fully compatible hote hain[span_5](start_span)[span_5](end_span).
  • Self-Describing Code: Metadata hone ki wajah se assemblies ko alag se documentation ki zaroorat nahi padti.

6. Cons (Hani / Disadvantages)

  • Complex Hierarchy: Deep namespaces ki wajah se code references lamba aur complex ho sakta hai.
  • Overhead: Metadata store karne ki wajah se assembly files ka size thoda badh jata hai.

7. Limitations (Simitations / Badhayein)

  • Custom value types aur reference types ke beech conversion (Boxing aur Unboxing) karne par extra performance overhead padta hai.

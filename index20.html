1. Complete Definition (Poori Paribhasha)

Managed Code: Aisa code jo direkt CLR (Common Language Runtime) ke control mein execute hota hai[span_0](start_span)[span_0](end_span). Iski memory management, security checks, aur garbage collection automatic hoti hai.

Unmanaged Code: Aisa code jo direct operating system dwara execute hota hai aur CLR ke control mein nahi hota (jaise C/C++ ki legacy DLLs ya Win32 API calls). Isme memory ko manually allocate (`malloc`) aur free (`free`) karna padta hai[span_1](start_span)[span_1](end_span).

4. Practical Code Example (P/Invoke for Unmanaged Interop in C#)

Neeche ek code snippet diya gaya hai jo batata hai ki kaise managed code unmanaged native DLLs ko call karta hai[span_4](start_span)[span_4](end_span):

// C# Example Demonstrating Interop between Managed Code and Unmanaged DLLs
using System;
using System.Runtime.InteropServices; // Required for P/Invoke

namespace UnmanagedInteropDemo
{
    class Program
    {
        // Importing an unmanaged native function from Windows user32.dll
        [DllImport("user32.dll", CharSet = CharSet.Auto)]
        public static extern IntPtr MessageBox(IntPtr hWnd, String text, String caption, uint type);

        static void Main(string[] args)
        {
            Console.WriteLine("--- Managed to Unmanaged Code Interop Demo ---");
            
            // Calling unmanaged Windows API function from managed C# code
            MessageBox(IntPtr.Zero, "Hello from Unmanaged Windows API!", "P/Invoke Demo", 0);
            
            Console.WriteLine("Interop executed successfully.");
            Console.ReadKey();
        }
    }
}

5. Pros (Labh / Advantages)

  • Managed Safety: Memory leaks aur pointer errors ka khatra nahi rehta kyunki GC active rehta hai[span_5](start_span)[span_5](end_span).
  • Platform Independence: MSIL ki wajah se code portable hota hai.

6. Cons (Hani / Disadvantages)

  • Performance Overhead: Runtime checks aur garbage collection ki wajah se unmanaged code ke mukable speed thodi slow ho sakti hai.

7. Limitations (Simitations / Badhayein)

  • Unmanaged code ke sath interact karte samay (P/Invoke ke zariye) marshaling overhead aur security permissions ka dhyan rakhna padta hai.

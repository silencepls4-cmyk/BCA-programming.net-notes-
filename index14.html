1. Complete Definitions (Poori Paribhasha)

Arrays: Array ek data structure hai jo ek hi naam ke under multiple elements (same data type ke) ko contiguous memory locations par store karta hai (jaise 1D, 2D, aur Jagged arrays)[span_1](start_span)[span_1](end_span).

Exception Handling: Yeh ek aisa mechanism hai jo run-time errors (jaise divide by zero, array index out of bounds) ko gracefully handle karta hai bina application ko crash kiye. Isme `try`, `catch`, `finally`, `throw`, aur user-defined exceptions shamil hain[span_2](start_span)[span_2](end_span).

4. Practical Code Example (Arrays & Exception Handling in C#)

Neeche ek complete code snippet diya gaya hai jo array traversal aur exception handling ko demonstrate karta hai[span_7](start_span)[span_7](end_span):

// C# Example Demonstrating Arrays and Exception Handling (Try-Catch-Finally)
using System;

namespace ArraysAndExceptionsDemo
{
    class Program
    {
        static void Main(string[] args)
        {
            Console.WriteLine("--- Arrays & Exception Handling Demo ---");

            // 1. Array Declaration and Initialization
            int[] scores = { 85, 90, 78, 92, 88 };
            Console.WriteLine("Array element at index 2: " + scores[2]);

            // 2. Exception Handling Mechanism
            try
            {
                Console.WriteLine("\nTrying to access invalid array index...");
                // This will throw IndexOutOfRangeException
                int invalidAccess = scores[10]; 
            }
            catch (IndexOutOfRangeException ex)
            {
                Console.WriteLine("Caught Exception: Index was outside the bounds of the array.");
                Console.WriteLine("Error Details: " + ex.Message);
            }
            finally
            {
                Console.WriteLine("Finally block executed: Resource cleanup completed safely.");
            }

            Console.WriteLine("Program executed successfully without crashing.");
            Console.ReadKey();
        }
    }
}

5. Pros (Labh / Advantages)

  • Application Stability: Exception handling ki wajah se unexpected errors par application crash nahi hoti[span_8](start_span)[span_8](end_span).

6. Cons (Hani / Disadvantages)

  • Performance Cost: Try-catch blocks ka heavy use runtime par thoda overhead create kar sakta hai agar unhe har jagah unnecessary lagaya jaye.

7. Limitations (Simitations / Badhayein)

  • Traditional arrays ki size fixed hoti hai; ek baar declare hone ke baad unki size ko dynamically runtime par change nahi kiya ja sakta (uske liye Collections use hote hain).

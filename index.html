01. .NET Framework Introduction & Architecture

विस्तृत उत्तर (15-Marks Long Format): .NET Framework माइक्रोसॉफ्ट द्वारा विकसित एक शक्तिशाली सॉफ्टवेयर विकास मंच है जो विंडोज, वेब और क्लाउड एप्लिकेशनों के निर्माण के लिए व्यापक वातावरण प्रदान करता है। यह विभिन्न प्रोग्रामिंग भाषाओं (C#, VB.NET, F#) को एक समान मंच पर जोड़ने का कार्य करता है।

वास्तुकला आरेख (Architecture Flowchart):

[C# / VB.NET Source Code] ↓ (Language Compiler) [MSIL / Intermediate Language + Metadata] ↓ (CLR & JIT Compiler) [Native Machine Code Execution]

लाभ (Advantages):

  • क्रॉस-लैंग्वेज इंटीग्रेशन और उच्च विकास गति (Development Speed)।
  • स्वचालित मेमोरी प्रबंधन (Garbage Collection)।

हानियां एवं सीमाएं (Disadvantages & Limitations):

  • प्रारंभिक निष्पादन में JIT कम्पाइलेशन के कारण हल्का विलंब।
  • पारंपरिक रूप से मुख्य रूप से विंडोज आधारित इकोसिस्टम पर निर्भरता।

02. CLR (Common Language Runtime) & Components

विस्तृत उत्तर (15-Marks Long Format): CLR .NET फ्रेमवर्क का मुख्य निष्पादन इंजन (Execution Engine) है। यह मेमोरी मैनेजमेंट, थ्रेड एग्जीक्यूशन, सुरक्षा जाँच, और अपवाद हैंडलिंग को प्रबंधित करता है।

मुख्य विशेषताएं:

  • प्रबंधित कोड (Managed Code) का सीधा संचालन।
  • सुरक्षा और कोड एक्सेस कंट्रोल (CAS)।

03. CTS, CLS and Managed Execution

विस्तृत उत्तर (15-Marks Long Format): Common Type System (CTS) सभी डेटा प्रकारों के लिए वैश्विक मानक तय करता है, जबकि Common Language Specification (CLS) विभिन्न भाषाओं के बीच आपसी संवाद (Interoperability) के नियम निर्धारित करता है।

04. Assemblies & Namespaces

विस्तृत उत्तर (15-Marks Long Format): Assembly (.dll या .exe) संकलित कोड की भौतिक इकाई है, जबकि Namespace तार्किक रूप से कक्षाओं को व्यवस्थित करने का माध्यम है।

05. Exception Handling & Try-Catch-Finally

विस्तृत उत्तर (15-Marks Long Format): रन-टाइम त्रुटियों को प्रबंधित करने और एप्लीकेशन को क्रैश होने से बचाने के लिए Try-Catch-Finally तंत्र का उपयोग किया जाता है।

try { int a = 10, b = 0; int c = a / b; } catch (Exception ex) { Console.WriteLine("Error: " + ex.Message); } finally { Console.WriteLine("Always Executed"); }

06. Multithreading & Background Operations

विस्तृत उत्तर (15-Marks Long Format): मल्टीथ्रेडिंग के माध्यम से एक ही समय में कई कार्यों को समानांतर रूप से निष्पादित किया जाता है, जिससे UI ब्लॉक नहीं होता।

07. C# Object-Oriented Programming (OOPs)

विस्तृत उत्तर (15-Marks Long Format): OOPs के चार मुख्य स्तंभ—Encapsulation, Inheritance, Polymorphism, और Abstraction—सॉफ्टवेयर डिजाइन को मॉड्यूलर बनाते हैं।

08. Inheritance, Polymorphism & Encapsulation

विस्तृत उत्तर (15-Marks Long Format): इनहेरिटेंस कोड पुन: उपयोगिता (Code Reusability) बढ़ाता है, और पॉलीमॉर्फिज्म एक ही नाम के कई रूप (Method Overloading/Overriding) प्रदान करता है।

09. Constructors, Destructors & Interfaces

विस्तृत उत्तर (15-Marks Long Format): कंस्ट्रक्टर ऑब्जेक्ट के आरंभिकरण (Initialization) के लिए उपयोग होता है, जबकि इंटरफेस मल्टीपल इनहेरिटेंस जैसी विशेषताओं को लागू करता है।

10. Abstract Classes & Method Overloading

विस्तृत उत्तर (15-Marks Long Format): एब्सट्रैक्ट क्लास आंशिक कार्यान्वयन प्रदान करती है, और मेथड ओवरलोडिंग एक ही क्लास में समान नाम के अलग पैरामीटर वाले फंक्शन्स की अनुमति देती है।

11. Windows Forms Architecture & Events

विस्तृत उत्तर (15-Marks Long Format): Windows Forms GUI आधारित डेस्कटॉप एप्लीकेशन बनाने के लिए .NET का क्लास लाइब्रेरी आधारित फ्रेमवर्क है।

12. Windows Forms Controls (Buttons, Textbox)

विस्तृत उत्तर (15-Marks Long Format): बेसिक कंट्रोल्स जैसे Button, TextBox, Label, और CheckBox यूजर से इनपुट लेने और आउटपुट दिखाने का कार्य करते हैं।

13. Advanced Controls & Dialog Boxes

विस्तृत उत्तर (15-Marks Long Format): TreeView, ListView, OpenFileDialog, और SaveFileDialog जैसे उन्नत कंट्रोल्स जटिल यूजर इंटरफेस बनाते हैं।

14. MDI Forms & Menu Implementation

विस्तृत उत्तर (15-Marks Long Format): Multiple Document Interface (MDI) एक मुख्य पेरेंट विंडो के भीतर कई चाइल्ड विंडो को प्रबंधित करने की अनुमति देता है।

15. ADO.NET Architecture & Data Providers

विस्तृत उत्तर (15-Marks Long Format): ADO.NET डेटाबेस कनेक्टिविटी के लिए Connected और Disconnected दोनों आर्किटेक्चर प्रदान करता है।

16. Connection & Command Objects

विस्तृत उत्तर (15-Marks Long Format): SqlConnection डेटाबेस से जोड़ती है और SqlCommand उसके माध्यम से SQL क्वेरी या स्टोर प्रोसीजर निष्पादित करती है।

17. DataReader vs DataAdapter

विस्तृत उत्तर (15-Marks Long Format): DataReader फॉरवर्ड-ओनली फास्ट डेटा स्ट्रीम है, जबकि DataAdapter डिस्कनेक्टेड डेटासेट को डेटाबेस से सिंक करता है।

18. Typed & Untyped Datasets

विस्तृत उत्तर (15-Marks Long Format): Typed Dataset मजबूत टाइप-सेफ़्टी और विजुअल स्कीमा प्रदान करता है, जबकि Untyped Dataset में कॉलम का एक्सेस इंडेक्स या स्ट्रिंग नेम से होता है।

19. CommandBuilder & Database Updates

विस्तृत उत्तर (15-Marks Long Format): CommandBuilder स्वचालित रूप से Insert, Update, और Delete कमांड जनरेट करता है जब डेटासेट में बदलाव किए जाते हैं।

20. Transaction Management in ADO.NET

विस्तृत उत्तर (15-Marks Long Format): ट्रांजैक्शन मैनेजमेंट सुनिश्चित करता है कि डेटाबेस ऑपरेशंस 'ACID' (Atomicity, Consistency, Isolation, Durability) नियमों का पालन करें।

21. ASP.NET Web Forms Architecture

विस्तृत उत्तर (15-Marks Long Format): ASP.NET वेब फॉर्म्स सर्वर-साइड इवेंट-ड्रिवन वेब एप्लीकेशन डेवलपमेंट के लिए एक मानक फ्रेमवर्क है।

22. ASP.NET Page Lifecycle & Events

विस्तृत उत्तर (15-Marks Long Format): पेज लाइफसाइकिल (Init, Load, PreRender, Unload) सर्वर पर पेज के निर्माण से लेकर नष्ट होने की प्रक्रिया को नियंत्रित करता है।

23. Validation Controls (Required, Range)

विस्तृत उत्तर (15-Marks Long Format): RequiredFieldValidator, RangeValidator, और CompareValidator क्लाइंट-साइड और सर्वर-साइड दोनों पर यूजर इनपुट की जाँच करते हैं।

24. Master Pages & Site Navigation

विस्तृत उत्तर (15-Marks Long Format): मास्टर पेज वेबसाइट के सभी वेब पेजेस के लिए एक समान लेआउट (Header, Footer, Sidebar) प्रदान करता है।

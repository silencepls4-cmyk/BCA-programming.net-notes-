Managed Execution Process & JIT Compilation

Definition (परिभाषा): .NET mein source code direct machine code mein compile nahi hota, balki ek do-चरण (two-step) managed execution process se gujarta hai[span_3](start_span)[span_3](end_span).

[Source Code] → [Roslyn Compiler] → [MSIL / IL Code] → [JIT Compiler] → [Native Machine Code]

Detailed Explanation (विस्तृत विवरण):

Sabse pehle source code Microsoft Intermediate Language (MSIL) aur Metadata mein convert hota hai[span_4](start_span)[span_4](end_span). Jab program run hota hai, tab Just-In-Time (JIT) compiler is MSIL ko CPU-specific native machine code mein badalta hai.

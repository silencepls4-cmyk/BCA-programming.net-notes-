UNIT I // ARCHITECTURE

Overview & Architecture

Definition (परिभाषा): The .NET Framework ek aesa software development platform hai jise Microsoft ne banaya hai. Yeh applications ko banane aur run karne ke liye ek surakshit aur unified environment provide karta hai.

Architecture & Structure (संरचना):

Isme do mukhya bhaag hote hain: CLR (execution engine) aur FCL (classes ka sangrah).

[User Application] → [.NET Framework Class Library] → [CLR Execution Engine] → [Operating System]

Advantages (लाभ)

  • Alag-alag languages ek sath kaam kar sakti hain.
  • Memory ka management automatic hota hai.

Disadvantages (हानि)

  • Shuruat mein system par thoda load padta hai.

Real-life Example (वास्तविक जीवन उदाहरण): Jaise ek bada shopping mall alag-alag dukano (modules) ko ek hi chhat ke niche chalata hai, waise hi .NET framework alag programs ko ek platform deta hai.

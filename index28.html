इकाई III (शेष टॉपिक): ट्रांजैक्शन मैनेजमेंट और कमांड बिल्डर

बीसीए पंचम (V) सेमेस्टर • विषय: सीएएससी-14T (.NET Programming) • शत-प्रतिशत परीक्षा-उपयोगी विस्तृत नोट्स

1. परिचय एवं परिभाषा (Introduction & Definition)

ADO.NET में डेटाबेस संचालन को पूर्ण और सुरक्षित बनाने के लिए Transaction Management (ट्रांजैक्शन मैनेजमेंट) और CommandBuilder (कमांड बिल्डर) अत्यंत महत्वपूर्ण घटक हैं।

ट्रांजैक्शन (Transaction) कार्यों का एक ऐसा समूह है जो 'सब कुछ या कुछ नहीं' (All or Nothing - ACID गुण) के सिद्धांत पर काम करता है। यदि समूह का एक भी कार्य विफल हो जाता है, तो सभी पिछले बदलाव स्वतः रद्द (Rollback) हो जाते हैं। दूसरी ओर, SqlCommandBuilder स्वचालित रूप से डेटासेट (DataSet) में किए गए बदलावों को डेटाबेस में वापस भेजने के लिए INSERT, UPDATE और DELETE जैसी SQL कमांड्स स्वतः उत्पन्न करता है।

2. मुख्य बिंदु एवं विशेषताएं (Key Points & Features)

  • ACID गुण: ट्रांजैक्शन के चार मुख्य स्तंभ—Atomicity, Consistency, Isolation, और Durability हैं।
  • Commit और Rollback: सभी कार्य सफल होने पर Commit() से डेटाबेस पक्का होता है, और त्रुटि होने पर Rollback() से पुराना डेटा सुरक्षित रहता है।
  • CommandBuilder: यह SqlDataAdapter के साथ मिलकर काम करता है ताकि डेवलपर को बार-बार इंसर्ट या अपडेट क्वेरी खुद न लिखनी पड़े।

3. वास्तुकला एवं प्रवाह आरेख (Architecture & Flowchart Diagram)

ट्रांजैक्शन मैनेजमेंट की कार्यप्रणाली का प्रवाह आरेख नीचे दर्शाया गया है:

+---------------------------------------------------------+
|                Begin Database Transaction               |
+---------------------------------------------------------+
                             ↓
+---------------------------------------------------------+
|           Execute Multiple SQL Operations               |
+---------------------------------------------------------+
                             ↓
         [क्या सभी ऑपरेशंस पूरी तरह सफल रहे?]
                   /                \
             (हाँ / Yes)          (नागवार / No)
               /                      \
+---------------------------+  +--------------------------+
|   Transaction.Commit()    |  |   Transaction.Rollback() |
| (स्थायी रूप से सेव करना)  |  | (पुराने स्टेट पर लौटना)   |
+---------------------------+  +--------------------------+

आरेख विवरण (Diagram Description): ट्रांजैक्शन शुरू होने के बाद सभी कमांड्स परखी जाती हैं। सफलता मिलने पर कमिट होता है और गलती होने पर रोलबैक के जरिए डेटा सुरक्षित रखा जाता है।

4. अनुप्रयोग (Applications)

इन तकनीकों का उपयोग निम्नलिखित क्षेत्रों में होता है:

  • बैंकिंग ट्रांजैक्शन (जैसे एक खाते से पैसे कटकर दूसरे खाते में जमा होना)।
  • ऑटोमेटेड डेटा अपडेट और सिंक करने की प्रक्रियाओं में।

5. लाभ, हानियां एवं सीमाएं (Pros, Cons & Limits)

### लाभ (Pros / Advantages):
  • डेटाबेस की अखंडता (Data Integrity) बनी रहती है और कभी भी डेटा आधा-अधूरा नहीं रहता।
  • कमांड बिल्डर के उपयोग से कोडिंग का समय बहुत बच जाता है।
### हानियां एवं सीमाएं (Cons & Limits):
  • कमांड बिल्डर केवल सिंगल-टेबल (Single table) परिदृश्यों के लिए सबसे अच्छा काम करता है, जटिल जॉइन (Complex Joins) के लिए यह सीमित है।

6. तुलना तालिका: Commit बनाम Rollback (Comparison)

तुलनात्मक बिंदु Commit (कमिट) Rollback (रोलबैक)
मुख्य कार्य डेटाबेस में किए गए सभी बदलावों को **स्थाई (Permanent)** करना। त्रुटि आने पर सभी बदलावों को **रद्द करके पूर्ववत** करना।
स्थिति यह केवल तब चलता है जब सभी प्रक्रियाएं सफल हों। यह तब सक्रिय होता है जब प्रक्रिया के दौरान कोई अपवाद (Exception) आए।

7. प्रोग्रामिंग कोड उदाहरण (Code Snippet)

सी# भाषा में ट्रांजैक्शन मैनेजमेंट (Try-Catch के साथ) का एक संक्षिप्त उदाहरण नीचे प्रस्तुत है:

using System; using System.Data.SqlClient; class TransactionExample { static void Main(string[] args) { string connString = "Server=myServerAddress;Database=myDataBase;Trusted_Connection=True;"; using (SqlConnection conn = new SqlConnection(connString)) { conn.Open(); SqlTransaction transaction = conn.BeginTransaction(); SqlCommand cmd = conn.CreateCommand(); cmd.Transaction = transaction; try { cmd.CommandText = "UPDATE Accounts SET Balance = Balance - 500 WHERE AccountID = 1"; cmd.ExecuteNonQuery(); cmd.CommandText = "UPDATE Accounts SET Balance = Balance + 500 WHERE AccountID = 2"; cmd.ExecuteNonQuery(); transaction.Commit(); // सफलता पर पक्का करना Console.WriteLine("ट्रांजैक्शन सफलतापूर्वक पूर्ण हुआ!"); } catch (Exception ex) { transaction.Rollback(); // त्रुटि पर वापस लौटना Console.WriteLine("त्रुटि के कारण ट्रांजैक्शन रद्द कर दिया गया: " + ex.Message); } } } }
